# Fixed equal-weight multitaper

`DpssTapers.withinBudget` constructs symmetric, unit-energy DPSS using Gale's portable symmetric eigensolver. The first subset is bounded to lengths 2 through 512, `0 < NW < length/2`, and an explicit number of leading candidates. Selection uses each candidate's measured band concentration and a caller-supplied floor in `[0,1]`. The result retains all candidate concentrations and selected indices. It does not infer a taper count, interpolate tapers, or use periodic DPSS.

`BoundedMultitaperPlan` applies those tapers to each complete multichannel frame. Detrending is explicitly `None` or `Mean`. Every taper uses the same frame and density normalization `1 / sqrt(sampleRate * taperEnergy)`. The cross product is `conj(first) * second`; one-sided interior bins receive a factor of two except DC and even-length Nyquist. Complex spectra receive equal weights within each frame; frame means then receive equal weights across accepted frames. Counts refer to frames, not tapers. A late failure in any taper leaves the accumulated frame count and values unchanged.

Primitive construction and runtime capacities are separately reported and admitted before allocation. The retained DPSS set, FFT plans/workspaces, candidate spectrum staging and exact accumulators are included; object overhead, GC retention and process RSS are excluded. Completed spectra own their data; merge requires the exact same plan. The public `CsdFrameAccumulator` also covers ordinary CSD, sharing the cross-periodogram implementation and exact frame accumulation.

The frozen NumPy 2.3.5/SciPy 1.18.1 reference covers odd/even windows, zero padding, detrending, concentration selection, phase and density. `tools/freeze-multitaper-reference.py` regenerates or checks the fixtures. Provider tests also cover Parseval, Hermitian/PSD laws, merge and order invariance, late-taper failure atomicity, missing/nonfinite input and budget refusal. No adaptive weights, jackknife intervals, degrees of freedom or comparative speed are qualified by this subset.
